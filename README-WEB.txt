نسخه وب پاسارگاد

روش اجرا روی کامپیوتر یا تبلت:
1) همه فایل‌های این پوشه را روی یک هاست یا سرور محلی قرار دهید.
2) فایل index.html را از طریق آدرس HTTP باز کنید؛ برای مثال با Live Server یا هر وب‌سرور ساده.
3) ورود پیش‌فرض: admin / 1234

نکته:
- این نسخه برای اجرا در مرورگر ساخته شده و اطلاعات محلی را در حافظه مرورگر (localStorage) نگهداری می‌کند.
- امکانات وابسته به Electron مانند چاپگرهای سیستم، پشتیبان‌گیری مستقیم فایل و انتخاب مسیر فایل در نسخه وب محدود هستند.
- برای استفاده چندکاربره و ذخیره مرکزی، باید نسخه سروری با API و دیتابیس آنلاین ساخته شود.
